# SilentPaper 使用说明

## 界面总览

- 底部三标签：**主页 / 应用 / 设置**；右下角为**锁屏**按钮。
- 顶部为日期、时间与状态行；界面为白纸黑字 + 1px 灰线，无卡片、无系统弹窗式对话框。
- 最低支持 Android 4.2（API 17）。

## 主页

- 应用按「固定到主页优先 → 点击次数」排序。
- 单击图标打开应用。
- 长按图标弹出操作菜单：
  - 固定到主页 / 取消固定
  - 隐藏应用
  - 应用信息
- 双击底部「主页」标签：打开最近任务。
- 顶部时钟：单击进入 WiFi 传书。
- 日期统一显示为「X月X日，星期X」。
- 底部右侧「锁」：通过设备管理器锁屏，首次使用需授权。

## 主页顶部风格

设置 → 网格与图标主页：

| 风格 | 布局 |
|---|---|
| 经典居中 | 日期、时钟、状态行居中；电池图标 + 百分比、WiFi、蓝牙横排 |
| 左右分栏 | 左侧时钟与日期，右侧电池 / 蓝牙 / WiFi 竖排，中间竖向虚线 |

- **状态图标风格**：线条 / 实心，同时作用于电池、WiFi、蓝牙（含纯文字快捷行）。
- 分栏模式下，整行可点击：蓝牙开关，WiFi 在 Android 10+ 直达系统设置、旧版本开关；长按均进系统设置。
- 顶部分割线随「主页分割线」开关显示 / 隐藏。

## 时钟样式与快捷行

设置 → 时钟：

- **时钟样式**：分栏 / 冒号 / 堆叠 / 数码管 / 胶囊 / 翻页 / 圆环 / 竖线 / 横排 / 线框 / 表盘 / 点阵（12 种）。
- **仅纯文字主页生效**：时钟对齐（左 / 中 / 右）、时间字号（0 = 自动，12–200sp）、
  时钟上下边距与左右偏移。图标主页保持原时间槽位（经典 76sp / 分栏 60sp 为基准），只换外观。
- **时钟字体**：为钟面数字单独指定字体（两主页共用；数码管 / 表盘 / 点阵为自绘，不受影响），
  默认「跟随 APP 字体」。
- **时钟周边字号**：统一调整日期行、状态行、快捷行与信息行的小字（10–32sp，0 = 自动），两主页共用。

图标主页与纯文字主页共用同一时钟区：图标主页隐藏顶部原生时间，由所选样式
接管原时间槽位；经典居中插在日期与状态行之间，左右分栏在左列原时间位置。
纯文字主页的时钟下方还有电池 / WiFi / 蓝牙快捷行与日期行。

- 圆环 / 表盘只绘制时间，日期仍显示在下方信息行；竖线 / 横排 / 点阵自带日期与电量，信息行自动隐藏。
- 点阵月历按月份自动使用 5 或 6 行，月末日期不丢失。
- 时钟样式改动即时生效；纯文字主页的对齐 / 字号调整即时生效。

充电时，电池图标框内绘制闪电（经典 / 分栏 / 纯文字快捷行三处同步）。

## 纯文字主页

设置最上方「主页样式」→ 纯文字：

- 不显示图标，应用名纵向单列排布，单击启动、长按弹出操作菜单。
- **文字字号 / 行间距 / 页边距**：点 − / + 调整；显示「自动」时按屏幕比例取值，
  点中间数值恢复自动。
- **列表对齐**（左 / 中 / 右）与**列表上 / 下 / 左 / 右边距**用于避让壁纸内容。
- **底部标语**：可编辑文字，并有独立显示开关。
- **长按应用 → 批量管理**：列表显示全部应用（○ 未选 / ● 选中 / 隐 已隐藏），
  单击文字切换选中，底部可批量隐藏 / 显示 / 卸载。
- **隐藏状态栏与导航栏**：开启后纯文字主页沉浸式全屏（仅主页页生效），
  从屏幕边缘内滑可临时唤出系统栏。

## 壁纸

设置 → 壁纸：

- **选择壁纸**：从相册 / 文件管理器选图，自动灰度化并按「淡化程度」混入纸色；
  等比裁切铺满整窗，不拉伸。
- **壁纸淡化**：开 = 与纸色混合（默认 60）；关 = 原图灰度直出。
- **淡化程度**：0–90% 可调，点中间数值恢复默认。
- 壁纸铺满整窗（含底部标签栏区域）；底部标签栏透明，底部标签与图标主页应用名
  使用纸色圆角底片，深色壁纸上仍可读；应用页 / 设置页保持纸色实底。
- **移除壁纸**：恢复纯纸色背景。

## 字体与字号

设置 → 字体：

- **APP 字体**：扫描 `/sdcard/Fonts`、Download 等目录；也可「从文件选择」或
  「从文件夹选择」（SAF 持久授权，Android 5.0+ 可用，Android 11+ 推荐）。对话框内逐行预览，
  点击即全局应用。
- **时钟字体**：为钟面数字单独指定字体（两主页共用；数码管 / 表盘 / 点阵为自绘），
  默认「跟随 APP 字体」。
- **字体粗细**：原样 / 加粗 / 加重 / 特粗（描边加粗，对自定义字体同样生效）。
- **界面字号**：80–140% 全局缩放（改后页面重建一次）；时钟大字与时钟周边
  小字有独立旋钮，不随界面字号缩放。

## 隐藏应用

- 长按应用 → 隐藏后，主页与应用页默认都不显示。
- 设置 → 网格与图标主页 → **隐藏应用在应用页可见**：开启后隐藏应用仍在应用页
  显示（淡化 + 右上角 ● 标记），可正常启动。

## 应用抽屉

- 左右或上下滑动均可翻页；页码显示在网格上方。
- 左上角「管理」进入批量模式：
  - 勾选应用后可**隐藏 / 显示 / 卸载**；
  - 点「完成」退出管理。
- 长按图标同样可固定、隐藏、查看应用信息。
- 应用安装 / 卸载 / 更新后列表自动刷新。

## 最近任务

- 打开方式：**双击底部「主页」标签**（或双击 HOME）。
- 关闭方式：再次按 HOME、点击弹窗外的空白区域，或点「取消」。
- 默认只显示**最近 30 分钟**内使用过的应用；可在设置中调整时间范围：
  **关 / 5分钟 / 30分钟 / 1小时 / 6小时 / 1天**。
- 标题右侧「清空」：清空当前最近任务列表并尝试清理后台。
- 「取消」按钮的行为可在设置中选择：
  - 回到上一应用（默认）
  - 回到桌面
- 需要 Android 5.0 及以上，并在系统设置中授予「使用情况访问」权限（或执行 `adb shell appops set com.silent.paper GET_USAGE_STATS allow`）。

## 设置

| 位置 | 内容 |
|---|---|
| 设置最上方 | 主页样式（图标网格 / 纯文字） |
| 网格与图标主页 | 应用列数/行数、应用分割线、主页列数/行数、主页分割线、主页顶部风格、状态图标风格、隐藏应用在应用页可见 |
| 时钟 | 时间字号、时钟样式、时钟对齐、时钟上下边距与左右偏移、时钟周边字号 |
| 纯文字主页 | 列表对齐与四向边距、文字字号、行间距、页边距、底部标语、沉浸式 |
| 壁纸 | 选择壁纸、壁纸淡化、淡化程度、移除壁纸 |
| 字体 | APP 字体、时钟字体、字体粗细、界面字号 |
| 图标 | 图标包、自动绘制线条图标 |
| 最近任务 | 仅显示近期使用（时间范围）、取消行为 |
| 底部 | 使用说明、关于（含赞赏提醒开关）、恢复默认 |

- 点击分类标题行可展开/收起该分类。
- 多选项在**底部弹窗列表**中选择，选中项以 **●** 标记。
- 「恢复默认」将全部设置恢复为默认值。

## 图标

- 默认开启**自动绘制线条图标**：根据应用原始图标生成黑色线条图标并缓存到本地。
- 可在设置中选择已安装的第三方图标包（支持 appfilter 映射）；未覆盖的应用回退系统图标。
- 切换图标包或线条图标开关时会自动清空/重建缓存。

## 状态信息

- **蓝牙**：单击开关；长按进入系统设置。Android 12 及以上未授予
  `BLUETOOTH_CONNECT` 时直接打开系统设置。
- **WiFi**：Android 10 及以上应用已无法原地开关，单击直达系统 WiFi 设置；
  Android 9 及以下单击开关；长按均进入系统设置。
- 电量百分比与电池图标实时刷新；充电时图标内显示闪电。
- 状态栏（Android 6.0+）使用纸色底 + 深色图标；更早版本保持系统默认。
- 日期统一显示为「X月X日，星期X」。

## 赞赏

- 关于页底部显示原作者的赞赏二维码（Android 4.4+；Android 4.2 / 4.3 因二维码库限制暂不显示）。
- 每按满 50 次 HOME 会弹出一次赞赏提醒；可在 **设置 → 关于 →「50 次 HOME 投喂提醒」** 关闭。

## WiFi 传书

- 单击顶部**时间**打开 WiFi 传书（需已连接 WiFi）。
- 手机在 **25025 端口**开启网页服务，电脑浏览器访问弹窗中显示的地址即可上传文件。
- 上传文件保存到内置存储的 `WIFI_transfer` 文件夹。
- Android 4.4+ 显示二维码；Android 4.2 / 4.3 因二维码库限制隐藏二维码，请在浏览器手动输入上方地址。
- Android 9 及以下首次使用需要授予存储权限。

## 权限说明

| 权限 | 用途 |
|---|---|
| `PACKAGE_USAGE_STATS` | 最近任务列表（使用情况统计） |
| `QUERY_ALL_PACKAGES` | 枚举已安装应用 |
| `REQUEST_DELETE_PACKAGES` | 管理模式下卸载应用 |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | WiFi 状态开关 |
| `BLUETOOTH` / `BLUETOOTH_ADMIN` / `BLUETOOTH_CONNECT` | 蓝牙状态开关 |
| `ACCESS_NETWORK_STATE` / `INTERNET` | WiFi 传书 |
| `KILL_BACKGROUND_PROCESSES` | 最近任务清理 |
| `WRITE_EXTERNAL_STORAGE`（仅 ≤28） | WiFi 传书写入文件 |
| `READ_EXTERNAL_STORAGE`（仅 ≤32） | 扫描字体目录（也可不授权，改用 SAF 文件夹） |

## 已知限制

- 最近任务依赖系统使用情况统计，暂不适用于 Android 4.2。
- 不同厂商的电池优化策略可能延迟后台清理效果。
