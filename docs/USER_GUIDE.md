# SilentPaper 使用说明

## 界面总览

- 底部三标签：**主页 / 应用 / 设置**；右下角为**锁屏**按钮。
- 顶部为日期、时间与状态行；界面为白纸黑字 + 1px 灰线，无卡片、无系统弹窗式对话框。
- 最低支持 Android 4.2（API 17）。

## 主页

- 应用按「固定到主页优先 → 点击次数」排序。
- 单击图标打开应用。
- 长按图标弹出操作菜单：
  - 固定到主页 / 取消固定
  - 隐藏应用
  - 应用信息
- 双击底部「主页」标签：打开最近任务。
- 顶部时间：单击进入 WiFi 传书。
- 底部右侧「锁」：通过设备管理器锁屏，首次使用需授权。

## 主页顶部风格

设置 → 网格与主页：

| 风格 | 布局 |
|---|---|
| 经典居中 | 日期、时间、状态行居中；电池图标 + 百分比、WiFi、蓝牙横排 |
| 左右分栏 | 左侧时间（等宽字体）与日期，右侧电池 / 蓝牙 / WiFi 竖排，中间竖向虚线 |

- **状态图标风格**：线条 / 实心，同时作用于电池、WiFi、蓝牙。
- 分栏模式下，整行（图标 + 状态文字）可点击开关 WiFi / 蓝牙；长按进入系统设置。
- 顶部分割线随「主页分割线」开关显示 / 隐藏。

## 应用抽屉

- 左右或上下滑动均可翻页；页码显示在网格上方。
- 左上角「管理」进入批量模式：
  - 勾选应用后可**隐藏 / 显示 / 卸载**；
  - 点「完成」退出管理。
- 长按图标同样可固定、隐藏、查看应用信息。
- 应用安装 / 卸载 / 更新后列表自动刷新。

## 最近任务

- 打开方式：**双击底部「主页」标签**（或双击 HOME）。
- 关闭方式：再次按 HOME、点击弹窗外的空白区域，或点「取消」。
- 默认只显示**最近 30 分钟**内使用过的应用；可在设置中调整时间范围：
  **关 / 5分钟 / 30分钟 / 1小时 / 6小时 / 1天**。
- 标题右侧「清空」：清空当前最近任务列表并尝试清理后台。
- 「取消」按钮的行为可在设置中选择：
  - 回到上一应用（默认）
  - 回到桌面
- 需要 Android 5.0 及以上，并在系统设置中授予「使用情况访问」权限（或执行 `adb shell appops set com.silent.paper GET_USAGE_STATS allow`）。

## 设置

| 分类 | 内容 |
|---|---|
| 网格与主页 | 应用列数/行数、应用分割线、主页列数/行数、主页分割线、主页顶部风格、状态图标风格 |
| 图标 | 图标包、自动绘制线条图标 |
| 最近任务 | 仅显示近期使用（时间范围）、取消行为 |
| 系统 | 使用说明、关于、恢复默认 |

- 点击分类标题行可展开/收起该分类。
- 多选项在**底部弹窗列表**中选择，选中项以 **●** 标记。
- 「恢复默认」将全部设置恢复为默认值。

## 图标

- 默认开启**自动绘制线条图标**：根据应用原始图标生成黑色线条图标并缓存到本地。
- 可在设置中选择已安装的第三方图标包（支持 appfilter 映射）；未覆盖的应用回退系统图标。
- 切换图标包或线条图标开关时会自动清空/重建缓存。

## 状态信息

- 单击 **WiFi / 蓝牙** 文字或分栏行直接开关；长按进入对应系统设置。
- Android 12 及以上，蓝牙开关未授予 `BLUETOOTH_CONNECT` 时会直接打开系统蓝牙设置。
- 电量百分比与电池图标实时刷新。

## WiFi 传书

- 单击顶部**时间**打开 WiFi 传书（需已连接 WiFi）。
- 手机在 **25025 端口**开启网页服务，电脑浏览器访问弹窗中显示的地址即可上传文件。
- 上传文件保存到内置存储的 `WIFI_transfer` 文件夹。
- Android 9 及以下首次使用需要授予存储权限。

## 权限说明

| 权限 | 用途 |
|---|---|
| `PACKAGE_USAGE_STATS` | 最近任务列表（使用情况统计） |
| `QUERY_ALL_PACKAGES` | 枚举已安装应用 |
| `REQUEST_DELETE_PACKAGES` | 管理模式下卸载应用 |
| `ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | WiFi 状态开关 |
| `BLUETOOTH` / `BLUETOOTH_ADMIN` / `BLUETOOTH_CONNECT` | 蓝牙状态开关 |
| `ACCESS_NETWORK_STATE` / `INTERNET` | WiFi 传书 |
| `KILL_BACKGROUND_PROCESSES` | 最近任务清理 |
| `WRITE_EXTERNAL_STORAGE`（仅 ≤28） | WiFi 传书写入文件 |

## 已知限制

- 最近任务依赖系统使用情况统计，暂不适用于 Android 4.2。
- 不同厂商的电池优化策略可能延迟后台清理效果。
